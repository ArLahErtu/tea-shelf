# CHANGELOG — «Чайная полка»

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), семвер условный.

## [2.1.0] — 2026-09-13 — структура и производительность

### Добавлено
- `vercel.json` с политиками Cache-Control (шрифты immutable, css/js/img SWR, html must-revalidate).
- `fonts/`: Manrope (variable) и Prata самохостом (woff2, cyrillic+latin, OFL) +
  `preload` кириллицы и `preconnect` к Supabase/jsDelivr в head каждой страницы.
- `modulepreload` для транзитивного графа модулей страницы — генерируется сборщиком.
- `docs/AUDIT.md` — аудит 2-го уровня: структура, замеры скорости, остаточный полиш.
- Линт слоёв зависимостей (core/features/pages/app) — 0 нарушений.

### Изменено
- `js/` разложен по слоям: `app.js` (корень композиции), `core/` (config, supabase, ui),
  `features/` (auth, gate, brew-timer, notifications, chat, chat-html, tea-modal,
  amount-modal, tisanes, unknowns), `pages/` (index, catalog, shelf, journal, profile, doc).
- Имена приведены к соглашению «страница = pages/<имя>.js», фичи — kebab-case.
- `css/` стал плоским: `chatbot.css → chat.css`, `pages/*.css → css/*.css`.
- `sw.js` v5: прекэш новых путей + шрифты.
- Полиш по emil-design-eng: ease-out у входа модалок, `:active` у чипов/табов/сегментов,
  симметричный уход тостов, ховер-подъём только у редких взаимодействий.

### Исправлено
- Убраны render-blocking запросы к fonts.googleapis.com/fonts.gstatic.com.
- Водопад модулей 3–4 уровня сведён к глубине ≤2 параллельными запросами.

## [2.0.0] — 2026-09-13 — редизайн «тихий чайный дом»

### Добавлено
- `journal.html` + `js/journal.js` — личный журнал страницей: лента по дням, оценки,
  заметки, расход, сводка, фильтры (поиск / чай / оценка / заметка), режим архива.
- `js/brewTimer.js` — таймер заваривания: окно-вопрос «Да / Нет», режимы
  «Проливы · гунфу» (время из карточки, +15 сек на пролив) и «Настоем» (2–4 мин),
  слайдер-переключатель, звук/вибрация по окончании, прогресс-бар, «+15 сек», «Сброс»,
  «Следующий пролив», выход в окно журнала.
- `js/gate.js` — маршрутизация «две страницы»: лонгрид только для гостей,
  сервисные страницы только для вошедших, возврат через `?next=` после входа.
- `js/notifications.js` — тумблеры уведомлений в профиле (почта / Telegram chat id).
- Фото профиля: загрузка в Supabase Storage (`user-avatars`) и подстановка в шапку.
- Раздел «Покупки» на полке: инлайн-список заканчивающихся чаёв + модалка докупки.
- Выбор чая для заваривания (FAB и кнопка «Заварил»): модалка со списком полки.
- Skip-link, явные `width/height` и `loading="lazy"` у изображений, `aria-*` у
  переключателей и таб-бара.
- `docs/ARCHITECTURE.md`, `docs/REDESIGN.md`, `docs/UIUX_REVIEW.md`.

### Изменено
- Главная (`index.html`) стала лонгридом только для незарегистрированных; вошедшие
  сразу попадают в `shelf.html`.
- Шапка: убраны бургер-меню и кнопка «Заварил»; добавлена иконка профиля с меню
  (почта, Профиль, Режим модератора, Выйти). На десктопе в шапку продублированы
  пункты нижнего таб-бара: Каталог, Полка, Журнал, ИИ-помощник.
- Нижний таб-бар: 5 слотов — Каталог, Полка, Заварил (FAB), Журнал, ИИ-ассистент
  (вместо «Ещё»). Плавающий FAB чата скрыт, чат открывают триггеры `data-open-chat`.
- Логотип: SVG-знак + текст; на ≤400px остаётся только знак.
- Стили вынесены из HTML в `css/base.css`, `css/components.css`, `css/pages/*.css`;
  base64-фото заменены файлами `img/photo-*.jpg` (страницы полегчали в 15–30 раз).
- Профиль: строки «Почта / Пароль» стали кнопками-якорями к формам; добавлен блок
  лимита ИИ из `get_user_limits`.
- `sw.js`: precache v4 с актуальным списком файлов (журнал, новые css/js, фото).
- `sitemap.xml`: публичные страницы (index, catalog, privacy); журнал не индексируется.
- `manifest.webmanifest`: theme/background — кремовый `#F4EEDD`.
- Политика: редакция от 13.09.2026, добавлен пункт о фото профиля.

### Исправлено
- `sw.js` v3 прекэшировал несуществующий `/js/notifications.js` — `cache.addAll`
  падал и installation не завершался; список приведён к фактическим файлам.
- Таймер гаснет при закрытии оверлея по Esc/клику по фону (MutationObserver).
- Гостевые тупики: ссылки «Полка/Журнал» у гостя больше не ведут в пустоту —
  gate возвращает на лонгрид и открывает вход.

### Удалено
- Бургер-меню и шторка `.sheet`, кнопка «Заварил» в шапке, плавающий FAB чата,
  инлайн-стили и base64-изображения из страниц.
