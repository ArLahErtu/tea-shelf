# Чайная полка ☕ — личный учёт чая (редизайн v2)

Веб-сервис личного учёта чая: остатки, журнал завариваний с оценками и таймером
проливов, список покупок, общий каталог чаёв с модерацией и ИИ-помощник на YandexGPT.

**Статус:** активное использование, сбор обратной связи.
**Визуальная версия:** v2 («тихий чайный дом»: кремовая бумага, волосяные линейки,
сериф Prata, нижний таб-бар на мобильных). Описание редизайна — `docs/REDESIGN.md`,
история изменений — `CHANGELOG.md`, устройство кода — `docs/ARCHITECTURE.md`.

## Модель страниц: «две страницы»

1. **Лонгрид `index.html`** — только для НЕзарегистрированных. Рассказывает о
   функционале и ведёт на полку. Вошедший пользователь автоматически уезжает
   в личный кабинет (`gate.js`), поэтому главная не мелькает после входа.
2. **Сервисное пространство** — начинается с входа и не содержит главной:
   - `shelf.html` — личная полка: остатки, разделы «Покупки», «Избранное и заявки», архив;
   - `journal.html` — личный журнал завариваний (лента, фильтры, архив);
   - `catalog.html` — общий каталог (публичен для гостей ради SEO; действия требуют входа);
   - `profile.html` — профиль: фото, почта, пароль, уведомления, план, удаление аккаунта.

Гость на сервисной странице уводится на лонгрид с `?next=…`; после входа возвращается
туда, куда хотел. Навигация вошедшего: шапка (десктоп) и нижний таб-бар (мобильные)
с одинаковым составом: **Каталог · Полка · Заварил · Журнал · ИИ-ассистент**.

## Что умеет (реализовано)

### Личная полка
- Вход/регистрация (Supabase Auth), данные только свои (RLS).
- Остатки в граммах, пакетиках или упаковках; статусы «Мало» / «Закончился».
- Список «Что докупить» отдельным разделом + модалка «отметить докупленное».
- Избранное (хотелки) и заявки на модерацию в разделе «Избранное и заявки».
- Тизаны (травяные сборы) и «неизвестные» чаи — секции инжектятся на полку.

### Заваривание и журнал
- Кнопка «Заварил» (карточка полки, шапка полки, FAB в таб-баре) сначала предлагает
  **таймер**: «Да / Нет».
  - **Да** — таймер с двумя режимами (переключение слайдером):
    - «Проливы · гунфу»: время первого пролива берётся из карточки чая, каждый
      следующий пролив длиннее (+15 сек, для минутных карточек +30 сек);
    - «Настоем»: таймер на 2–4 минуты с пресетами.
    По окончании — звук, вибрация, подсветка; «Следующий пролив» продолжает сессию.
  - **Нет** (или «Готово — в журнал») — окно заполнения журнала: количество,
    оценка ★★★★★, заметка; списание остатков атомарно через RPC `brew_tea`.
- `journal.html` — лента завариваний по дням: оценки, заметки, расход, фильтры
  (поиск, чай, оценка/заметка) и переключение в архив журнала.

### Общий каталог
- Поиск по названию, региону и тегам; чипы быстрого фильтра + полный селект типов;
  сортировки (популярность, название, новизна).
- Карточка чая с параметрами заваривания (температура, время, доза, проливы).
- «На полку» с выбором количества и порога «мало»; избранное.
- «Предложите свой чай» — заявка на модерацию.

### Чат-помощник (кнопка «ИИ-ассистент»)
- Открывается из шапки и из таб-бара (плавающий FAB скрыт в CSS).
- Командный режим: «Добавь Сенча 100г», «Заварил Пуэр 7г», «Что докупить?», «Статистика».
- ИИ-режим (YandexGPT) с учётом полки и журнала; лимит 7 запросов/день на бесплатном
  тарифе, счётчик в модалке чата и в профиле.
- История диалогов 7 дней в localStorage; уведомления о модерации заявок.

### Модерация и профиль
- Меню аватара в шапке: почта, **Профиль**, **Режим модератора** (только для ролей),
  **Выйти**. Бургер-меню и кнопка «Заварил» из шапки убраны.
- Режим модератора: pending-заявки, одобрение с редактированием, отклонение с причиной,
  редактирование карточек, SEO-загрузка фото.
- Профиль: фото профиля (Supabase Storage, bucket `user-avatars`), смена почты и пароля,
  тумблеры уведомлений (почта / Telegram), план и лимит ИИ, удаление аккаунта (RPC).

### Прочее
- PWA: манифест, иконки, офлайн-снапшот полки, service worker (cache-first).
- Аналитика: Яндекс Метрика (только после согласия) + Vercel Analytics.
- Адаптив: на экранах ≤400px логотип сжимается до знака; safe-area для таб-бара.
- Доступность: skip-link, `:focus-visible`, `aria-*` на переключателях,
  `prefers-reduced-motion`, явные `width/height` и `loading="lazy"` у изображений.

## Стек

- **Фронтенд:** чистые HTML + модульный CSS + Vanilla JS (ES-модули, без сборщиков).
- **Бэкенд:** Supabase (Postgres + Auth + RLS + Storage + RPC + Edge Functions).
- **ИИ:** YandexGPT (yandexgpt-lite) через Supabase Edge Function `ai-assistant`.
- **Хостинг:** Vercel (автодеплой с main), publish-каталог — корень репозитория.

```

  chat.css        окно чат-помощника
  index.css catalog.css shelf.css journal.css profile.css   стили страниц
js/
  app.js          корень композиции: initCommon() на каждой странице
  core/           config.js · supabase.js · ui.js          — инфраструктура
  features/       auth · gate · brew-timer · notifications · chat · chat-html ·
                  tea-modal · amount-modal · tisanes · unknowns   — домен
  pages/          index · catalog · shelf · journal · profile · doc — точки входа
fonts/            Manrope (var) + Prata, woff2 cyrillic/latin
img/              favicon, иконки PWA, фото лендинга
docs/             ARCHITECTURE.md · REDESIGN.md · UIUX_REVIEW.md · AUDIT.md

```

Правила слоёв: `core` не знает о домене, `features` импортируют только `core`,
`pages` — `core` + `features`, связывает всё `app.js`. Граф модулей страницы —
звезда глубиной ≤2, без баррелей и прокси.

## Скорость

- Шрифты самохост + `preload` кириллицы: ноль сторонних render-blocking origin.
- `preconnect` к Supabase и jsDelivr; `modulepreload` графа модулей страницы
  (генерируется сборщиком из импортов).
- `vercel.json`: шрифты immutable 1 год; css/js/img — 1 день + stale-while-revalidate
  7 дней; html и sw.js — must-revalidate.
- SW v5: прекэш фактических файлов, офлайн-снапшот полки.
- Изображения: явные `width/height` (нет CLS), `loading="lazy"`, `fetchpriority="high"`
  у LCP-фото.
- Замеры и обоснования: `docs/AUDIT.md` (запросов на страницу 10–20, глубина графа ≤2).

## База данных (Supabase)

### Таблицы
- `tea_catalog` — общий каталог (id, name, type, region, description, temp, time, grams, steeps, tags, status, author_id, photo_url, popularity).
- `user_shelf` — личная полка (user_id, tea_id, amount, unit, low_threshold, favorite).
- `brew_journal` — журнал завариваний (user_id, tea_id, amount, unit, rating, note, created_at).
- `brew_journal_archive` — очищенный журнал (та же форма строк).
- `wishlist` — избранное (user_id, tea_id).
- `user_roles` — роли (user_id, role: 'user' | 'moderator' | 'admin').
- `user_subscriptions` — подписки и лимиты ИИ (user_id, plan, daily_requests_used, premium_until).
- `user_notifications` — уведомления (user_id, email, telegram_chat_id).
- `profiles` — профиль (user_id, avatar_url, updated_at).
- `ai_request_log`, `moderation_log`, `herbs`, `user_tisanes`, `unknown_teas`.

### RPC-функции
- `brew_tea(p_shelf_id, p_amount, p_rating, p_note)` — атомарное списание + запись в журнал + популярность+1.
- `get_pending_teas()`, `approve_tea(...)`, `reject_tea(...)`, `update_tea(...)`.
- `get_user_limits(p_user_id, p_timezone)`, `increment_ai_request(p_user_id, p_timezone)`.
- `delete_account()` — каскадное удаление данных пользователя.

### RLS-политики
- `tea_catalog`: select = published OR автор; insert = authenticated+pending; update/delete = автор (только pending) или модератор (через RPC).
- `user_shelf`, `brew_journal`, `wishlist`, `user_subscriptions`, `user_notifications`, `profiles`: только свои данные.

## Локальный запуск

1. Любым статическим сервером: `npx serve` или Live Server в VS Code.
2. Ключи Supabase уже в `js/config.js`; для своего проекта — заменить `SUPABASE_URL` /
   `SUPABASE_ANON_KEY` (Dashboard → Settings → API).
3. Схема БД: таблицы и RPC применены SQL-блоками (Supabase Dashboard → Database → Migrations).
4. Bucket `user-avatars` (public) — для фото профиля; bucket фото каталога — как ранее.

Тестовые аккаунты отключены (`SHOW_DEMO_ACCOUNTS = false` в `config.js`).

## Деплой

Статика без сборки: репозиторий импортируется в Vercel с пресетом «Other»,
publish-каталог — корень репозитория. Автодеплой с ветки `main`.

## Edge Functions (Supabase)

- `ai-assistant` — ИИ-ассистент на YandexGPT с проверкой лимитов и историей запросов.
- Секреты: `YANDEX_API_KEY`, `YANDEX_FOLDER_ID`, `SERVICE_ROLE_KEY`.
