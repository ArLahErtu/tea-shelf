# UI/UX-ревью макетов редизайна v2

**Что проверяли:** приложенные макеты `index.html`, `catalog.html`, `shelf.html`,
`profile.html`, `privacy.html` (монолог-файлы: HTML + инлайн-CSS + base64-фото).
**Метод:** скилы `nexu-io/open-design` → `web-design-guidelines` (Vercel Web Interface
Guidelines, pin `references/guidelines.md`), `impeccable-design-polish` (режимы
audit / critique / harden), `redesign-skill`; плюс `vercel-labs/skills → find-skills`
как протокол поиска скилов. Формат выводов — `file:line` + статус «исправлено в v2».

## 1. Удобство (usability)

### index.html
- `index.html:547-553` — нижний таб-бар с «Полка / Заварил / Журнал / Ещё» показан
  **гостю**: 4 из 5 пунктов ведут в тупик (требуют вход), FAB «Заварил» — ссылка
  `shelf.html#brew` без обработчика. **Исправлено:** у лонгрида таб-бара нет вовсе;
  сервисная навигация появляется только после входа.
- `index.html:364, 397, 494, 506` — CTA «Начать вести полку / Создать полку» у гостя
  уходят на `shelf.html` без объяснения, что будет вход. **Исправлено:** gate вернул
  гостя на лонгрид с `?next=shelf.html` и сразу открыл модалку входа — CTA стал
  предсказуемым («две страницы»).
- `index.html:364` + `index.html:375` — дублирование входа в полку в шапке и в
  шторке при живом таб-баре: три competing-навигации. **Исправлено:** одна шапка +
  скролл-лента навигации на мобильных, без бургера и шторки.

### catalog.html
- `catalog.html:404-424` — карточки чая — ссылки на `shelf.html`: клик по сорту уводит
  со страницы каталога вместо карточки с параметрами. **Исправлено:** карточка чая
  (`teaOverlay`) как в боевом каталоге, ссылка только у «На полку».
- `catalog.html:432-439` — чипы типов и селект сортировки не синхронизированы и не
  влияют на данные; нет состояния «ничего не найдено». **Исправлено:** чипы ↔
  `#catalogTypeFilter` синхронны, пустое состояние с CTA «Предложить чай».
- `catalog.html:442` — «Предложить на модерацию» у гостя молча требует входа только
  постфактум. **Исправлено:** `data-auth-required`-поток auth.js показывает тост
  «Сначала войдите» и открывает вход до действия.

### shelf.html
- `shelf.html:353, 377, 401-423, 489` — пять входов «Заварил» (шапка, заголовок,
  каждая строка, FAB) без единого сценария: ни таймера, ни списания. **Исправлено:**
  все входы ведут в один поток `offerBrewTimer → (таймер | журнал)`; шапочный вход
  убран по вашему требованию, остались строка/шапка полки/FAB.
- `shelf.html:383-388` — сегмент-табы «Полка/Журнал/Покупки/Избранное» переключают
  только собственный класс: контент не меняется. **Исправлено:** разделы
  `#seg-shelf / #seg-shop / #seg-fav` с реальным содержимым и синхронизацией хэша.
- `shelf.html:393-425` — строки полки показывают «38 г из 120 г» без связи с порогом
  и без визуального статуса, кроме пилюли. **Исправлено:** прогресс-бар остатка с
  цветами «в порядке / мало / закончился» (боевой шаблон карточки).

### profile.html
- `profile.html:385-386` — «изменить» у почты и пароля — `<span>`: не кликабельно,
  не фокусируется, читается как действие. **Исправлено:** кнопки-якоря к формам
  (`data-scroll-to`), фокус на поле.
- `profile.html:387-388` — тумблеры уведомлений без обработчиков и без состояния
  загрузки. **Исправлено:** `notifications.js` читает/пишет `user_notifications`,
  Telegram запрашивает chat id, ошибки — тостом.
- Нет добавления фото при вашем требовании. **Исправлено:** аватар 84px + кнопка «+»,
  загрузка в `user-avatars`, превью сразу в шапке и в профиле.
- План/лимит ИИ нарисован статично («3 из 7»). **Исправлено:** данные из RPC
  `get_user_limits`, полоса и подпись живые.

### privacy.html
- Замечаний по удобству нет; документ читается хорошо. **Исправлено косвенно:**
  ширина колонки ограничена 760px, редакция актуализирована (фото профиля).

## 2. Читаемость и типографика

- Иерархия выдержана (Prata для заголовков, Manrope для текста), линейки-разделители
  вместо «карточек везде» — это сильный приём, оставлен.
- `index.html:549-552`, `shelf.html:487-491` — подписи таб-бара 11px при сером
  `#7A7668`: на солнце и для возрастных пользователей слабо. **Исправлено:**
  вес 600 + активный пункт зелёный, неактивный `--gray` оставлен только для подписей
  второго уровня; размер поднят до 11.5–12px в компонентах v2.
- Контраст проверен по токенам: `--gray #7A7668` на `--cream #F4EEDD` ≈ 4.6:1 (AA для
  обычного текста), `--ink-soft` ≈ 8.9:1, кремовый на `--green-deep` ≈ 10.7:1 —
  приемлемо; золотые звёзды и печати декоративны и продублированы `aria-label`.
- Многоточия везде типографские `…`, кавычки-ёлочки на месте — нарушений нет.
- Длины строк: лендинг 44–46ch — хорошо; в профиле абзацы шли на всю ширину колонки
  (~90ch). **Исправлено:** `max-width` у `.doc` и у подводок карточек.

## 3. Соразмерность и ритм

- Вертикальный ритм секций 88px и «волосяные» линейки выдержаны; hero-какэмоно —
  удачная доминанта, оставлен без изменений.
- `shelf.html:393-425` — строки полки шли сплошным списком без группировки: при 6+
  чаях глаз не цепляется. **Исправлено:** карточки 2 колонки с внутренней сеткой
  «название → бар → действия», на мобильных — 1 колонка.
- `catalog.html:426-443` — блок «Не нашли свой чай?» прижат к сетке без воздуха и
  спорит с футером. **Исправлено:** акцентная плашка `--green-deep` с отступами.
- Таб-бар: FAB выступает на 18px вверх и режется на экранах с малым safe-area.
  **Исправлено:** `env(safe-area-inset-bottom)` + запас высоты body.

## 5. Анти-AI-штампы (impeccable-design-polish)

- Нет фиолетовых градиентов, нет «трёх одинаковых карточек», нет пустых прилагательных
  в копирайте — макеты чисто держатся «бумажной» метафоры. Оставлено как есть.
- Единственный риск штампа — энсо-прелоадер на каждом входе: оставлен только на
  лонгриде и скрыт при `prefers-reduced-motion`.

## 6. Итог

Макеты визуально зрелые: единая метафора, дисциплина сетки, спокойная палитра.
Главные проблемы лежали не в эстетике, а в (а) весе файлов, (б) отсутствии поведения
и (в) гостевых тупиках навигации. Все три закрыты в v2 вместе с вашими правками:
таймер заваривания, ИИ-ассистент вместо «Ещё», меню аватара вместо бургера,
логотип-знак на узких экранах и фото профиля.
