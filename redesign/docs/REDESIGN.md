# Редизайн v2 «Чайная полка» — спецификация визуала и переноса

## 1. Метафора и токены

«Тихий чайный дом»: кремовая бумага, волосяные линейки вместо теней и карточек
там, где можно, сериф Prata для заголовков и цифр, Manrope для интерфейса,
печать-ханко и вертикальные надписи как акценты.

```
--cream  #F4EEDD  фон страницы            --ink      #161614  текст
--paper  #FAF6EC  поверхности             --ink-soft #4B483F  вторичный текст
--green  #2F5D3C  действие                --gray     #7A7668  подписи
--green-deep #24463A  акцентные полосы    --seal     #B5442C  опасность/печать
--green-tint #E8F0E8  заливки              --gold     #C89C73  звёзды/«мало»
--line   #DDD6C2  границы                 --hair     #C9C2AC  волосяные линейки
--r 18px / --r-sm 12px                    --serif Prata / --sans Manrope
```

Правила: радиусы 18/12/999; тени только у зелёной кнопки и модалок; hover — подъём
на 2–4px или заливка tint; фокус — зелёное кольцо `:focus-visible`.

## 2.Breakpoints

| Ширина | Поведение |
|---|---|
| >960px | сетки 3 колонки, подвал 4 колонки |
| 861–960px | каталог 2 колонки, подвал 2 колонки |
| ≤860px | сервисные страницы: навигация шапки скрыта, живёт нижний таб-бар; страницы без таб-бара (лонгрид/профиль/документы) — навигация второй строкой шапки |
| ≤620px | каталог/полка 1 колонка, журнал 2 колонки |
| ≤400px | логотип сжимается до знака, паддинги 18px |

## 3. Шапка и навигация

- Состав шапки: логотип (знак + слово), навигация, справа — кнопка «Войти» у гостя
  или аватар с меню у вошедшего (почта, Профиль, Режим модератора, Выйти).
- Десктоп-навигация сервисных страниц дублирует таб-бар: Каталог, Полка, Журнал,
  ИИ-помощник (`data-open-chat`).
- Бургера и шторки нет ни на одной странице.
- Таб-бар (моб.): Каталог · Полка · **Заварил (FAB)** · Журнал · ИИ-ассистент.
  FAB на полке открывает выбор чая, на других страницах уводит на `shelf.html#brew`.

## 4. Страницы

### index.html — лонгрид (гости)
Прелоадер-энсо → hero с какэмоно → бегущая лента типов → «Что умеет полка»
(6 ячеек на волосяных линейках) → «Три шага» → «Из каталога — вживую» (топ-3 живых)
→ полоса тишины → финальный CTA. Вошедшие не видят страницу (gate).

### catalog.html
Заголовок + «Предложить чай» → липкая панель: поиск-пилюля, чипы типов, сортировка →
тумблер «Каталог/Модерация» для ролей → сетка карточек → «Показать ещё» →
акцентная плашка заявки. Карточка: фото 4:3, название, регион, пилюля заваривания,
футер с популярностью и «на полке».

### shelf.html
Заголовок с действиями («Заварил», «Архив чая», «Журналы») → баннер «заканчивается» →
сводка 4 числами на линейках → сегмент-табы → разделы: полка (фильтры + карточки +
инжект тизанов/неизвестных), покупки (инлайн-список + модалка докупки), избранное и
заявки (две панели).

### journal.html
Заголовок → сводка (завариваний, средняя, разных чаёв, за месяц) → липкая панель
фильтров (поиск, чай, чипы оценки, счётчик) → лента, сгруппированная по дням:
дата / название + заметка + расход / звёзды. Кнопка «Архив журнала» переключает
источник на `brew_journal_archive`.

### profile.html
Две колонки: слева карточка профиля (аватар 84px с кнопкой фото, почта, «с нами с…»,
строки настроек с тумблерами, план с полосой лимита ИИ), справа — безопасность
(пароль, почта), блок 152-ФЗ и опасная зона удаления.

### privacy.html / 404.html
Документ в колонке 760px с пилюлей редакции; 404 — тихая страница со знаком 迷 и
двумя выходами.

## 5. Новые компоненты v2

- **Таймер заваривания:** оверлей-вопрос → оверлей таймера: слайдер-переключатель
  режимов (полозь ездит трансформом), серифные цифры `m:ss`, строка пролива,
  температура и доза из карточки, прогресс-бар, кнопки «+15 сек / Старт-Пауза /
  Сброс», «Следующий пролив» после окончания, зелёная «Готово — в журнал».
- **Выбор чая:** узкая модалка со списком полки (название + остаток + время).
- **Сегмент-табы и тумблеры:** пилюля-трек с бумажным полозом.
- **Лента журнала:** строка 64px / 1fr / auto, звёзды золотом, дата табличными цифрами.

## 6. Структура и перенос (v2.1)

Структура выровнена по слоям (подробно — `docs/ARCHITECTURE.md`, обоснование замеров —
`docs/AUDIT.md`): `js/app.js` + `js/core/` + `js/features/` + `js/pages/`, css плоско,
шрифты самохостятся в `fonts/`, кэширование описано в `vercel.json`.

```
cp -R redesign/* <корень репозитория>/
```

Переносится всё, кроме неизменяемого: `robots.txt`, файлов верификаций,
`img/favicon.svg`, `img/icon-*.png|svg`, Edge Functions и схемы БД.
Старые `js/*.js` и `css/pages/*` из v1/v2.0 удалить при переносе (заменены новыми путями).
После деплоя проверьте: вход → полка; «Заварил» → таймер → журнал; меню аватара;
фото профиля; журнал; чат из таб-бара; заголовки Cache-Control в Network.

## 7. Что намеренно не меняли

- Боевые js-модули каталога/полки/чатa/модерации — только точечные вставки
  (таймер, чипы, разделы, уведомления), чтобы не потерять стабильность.
- ID-контракты оверлеев и шаблонов — страницы содержат прежние id, поэтому
  функционал переезжает без переписывания логики.
- Палитра и метафора макетов — они и есть новый визуальный язык.
